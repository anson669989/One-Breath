# 喘口氣（One Breath）

[English](README.en.md) | 繁體中文

手指又自己點開 Instagram 了嗎？喘口氣會在分心 App 打開之前，先陪你深呼吸幾秒。想開還是開得了，只是這一次，是你自己決定要開。

它不封鎖、不說教，也不會把你鎖在外面。等幾秒，按 **我確定，繼續開「Instagram」** 就進得去；按「算了，不開了」就回到桌面。

## 用起來是這樣

### 打開之前，先喘一口氣
你選好的 App 一打開，會先出現一顆慢慢呼吸的光球，和一句小小的問題，像是「你打開它是為了什麼？」。下面寫著今天第幾次打開它。

等幾秒之後（預設 5 秒，可以調成 0～30 秒），繼續開的按鈕才會慢慢浮現。畫面上刻意不放倒數，你不用盯著秒數等。選了繼續，接下來幾分鐘內（預設 5 分鐘，可以設 1～30 分鐘）再打開同一個 App，就不會再被打斷。

### 用久了，問你一聲
一直停在同一個 App 上，每用滿一段時間（預設 10 分鐘，可以設 1～60 分鐘），會再跳出來問你一次，例如「還要繼續嗎？」。可以選「夠了，先離開」，或「再用一下」。這個提醒畫面有自己的等待秒數。只算 App 真的在螢幕最前面的時間，螢幕關掉就不算。

### 用群組整理
把 App 分成幾組，例如「社群」「影音」「遊戲」。每一組自己決定要不要「開啟前喘口氣」、「使用中提醒」、「連同對應網站一起提醒」，也可以有自己的等待時間。一個 App 只會在一個群組裡。

### 網站也算
選了 X、YouTube 這類有網站的 App，用瀏覽器開 x.com、youtube.com 也會提醒。沒有 App 的網站，可以在群組的「自訂網站」自己加，例如 `news.example.com`。支援 Chrome、Samsung Internet、Firefox、Edge、Brave、Opera、DuckDuckGo 等瀏覽器。

### 看見今天的自己
首頁會顯示今天喘了幾口氣，還有幾次決定不開了。不打分數，也不排名，只是讓你看見。

想暫時全部停掉？「設定」分頁最下面有「啟用提醒」總開關。關掉就全部暫停，群組和設定都會保留。

### App 裡有三個分頁
- **首頁**：無障礙權限有沒有開（沒開會一步步教你）、今天的次數、群組摘要。
- **群組**：每個群組一張卡片，看得到裡面的 App 圖示、開了哪些提醒，也可以直接開關整個群組。點進去可以改名稱、提醒方式、時間和自訂網站，並在「App」分頁搜尋、勾選要放進來的 App。
- **設定**：全域的時間設定、語言、關於與隱私說明，最下面是「啟用提醒」總開關。

## 你的資料只在你的手機上
- 喘口氣沒有網路權限，沒有廣告，也不用註冊帳號。
- 設定、群組和每天的次數，都只存在這支手機裡，App 不會把它們傳到任何地方。如果你開了 Android 系統本身的備份，系統備份可能會一併包含這些設定。
- 它需要「無障礙」權限，用途只有一個：知道現在最前面的是哪個 App。在瀏覽器裡，它只讀網址列上的網址，用來認出你選的網站；網頁內容和畫面上的其他文字一律不讀。
- 程式碼全部在這個 repo 裡，可以自己檢查。

## 安裝
需要 Android 8.0 以上的手機。

### 下載 APK
到 [Releases 頁面](https://github.com/anson669989/One-Breath/releases/latest)下載最新版的 APK 檔，不需要登入 GitHub。

想自己建置的話，請看[開發說明](docs/DEVELOPMENT.md)。

### 裝好之後
1. 把 APK 傳到手機，點開安裝。第一次會問你要不要允許「安裝未知應用程式」。
2. 打開喘口氣，在首頁按 **① 開啟無障礙權限（找「喘口氣」）** → 已安裝的應用程式 → 喘口氣 → 開啟。回到 App，首頁變成「✓ 運作中」就好了。
3. 開關是灰色的、按不下去？這是 Android 13 以上對自行安裝 App 的保護。回到喘口氣按「開啟 App 資訊頁」→ 右上角 ⋮ →「允許受限制的設定」，再回去開一次無障礙。
4. 到「群組」分頁按「＋ 新增群組」，選一個範本或自己取名字，在「App」分頁勾選想提醒的 App，按「儲存」。
5. 三星手機建議再做一步：打開手機的系統設定（不是喘口氣裡的「設定」分頁）→ 電池 → 喘口氣 → 設為「不受限制」，免得被省電機制關掉，提醒突然失靈。

之後有新版，直接安裝蓋過去就好，設定會留著。從很早的舊版升級的話，原本勾選的 App 會自動放進一個叫「我的 App」的群組。

## 語言
介面有繁體中文和 English。在「設定」分頁的「語言 / Language」選「跟隨系統」、「繁體中文」或「English」，選了馬上換。

選「跟隨系統」時，手機的第一個語言是中文就顯示繁體中文，其他語言顯示英文。桌面上的 App 名稱，和系統無障礙設定裡的說明文字，則是跟著手機的系統語言。
